# 3D Prompt Atlas

3D制作の参考事例を「眺めてコピーする資料集」ではなく、目的から関連事例を探し、設計原理を抽出し、制作指示へ組み替えるための個人向けワークベンチです。

## 目的

- Tripo 3D Prompts などの公開事例を参照元付きで整理する
- 元資料を勝手に改変・再配布せず、メタデータ・URL・自分で抽出した設計原理を中心に保持する
- 「何を作りたいか」から複数事例を横断検索する
- 複数事例の有用な技法を組み合わせ、Astra / Three.js / Blender 等向けの制作指示を生成する
- 自分で成功したプロンプト・修正履歴・成果を別レイヤーとして蓄積する

## 現在地

Phase 0: 調査・設計中。

> 注意: 2026-09-08時点で、このGitHubリポジトリは Public と確認されています。第三者のプロンプト本文や画像等の収録は行わず、まず Private 化と権利・出典ルールを確定します。

## 想定構成

- `index.html` — 検索・入口
- `style.css` — UI
- `app.js` — 検索・合成ロジック
- `manual.html` — 使い方
- `data/` — 出典メタデータと自作の分析データ
- `docs/` — 要件・設計・決定・進捗

## データ方針

参照元の全貌は失わない一方、第三者コンテンツを無断で複製することは避けます。基本は以下を保持します。

- source URL
- title / model / author / date
- source type（作者原文 / source-derived brief / GitHub 等）
- 技術・用途・操作・表現などの自作タグ
- 自分で抽出した設計原理
- 自分の制作指示・修正履歴・成功例

原文全文・画像・コードは、ライセンスまたは利用条件を確認できたものだけ別扱いにします。
